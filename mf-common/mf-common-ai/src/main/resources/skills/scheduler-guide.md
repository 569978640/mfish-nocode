## 任务调度系统

平台基于 **Quartz** 调度框架，提供可视化的定时任务管理。

### 核心功能
1. **任务管理**：创建、修改、删除定时任务
2. **任务执行**：手动触发、暂停、恢复任务
3. **执行日志**：查询任务执行历史和结果
4. **任务回调**：配置任务执行后的回调通知
5. **任务订阅**：订阅任务执行状态通知

### 任务配置
1. 进入「调度管理 → 定时任务」
2. 新增任务，配置：
   - 任务名称、任务分组
   - 调度类型：Cron 触发器 / Simple 触发器
   - Cron 表达式（如 `0 0 2 * * ?` 每天凌晨2点执行）
   - 调用目标（要执行的 Job 类或接口）
   - 执行参数
3. 保存后任务自动开始调度

### Cron 表达式说明
格式：`秒 分 时 日 月 周`
- `0 0 2 * * ?` — 每天凌晨2点
- `0 */5 * * * ?` — 每5分钟
- `0 0 8 ? * MON-FRI` — 工作日早上8点
- `0 0 0 1 * ?` — 每月1号零点

### 数据表结构
- `qrtz_job`：任务配置主表
- `qrtz_job_log`：任务执行日志
- `qrtz_job_subscribe`：任务订阅配置

### 执行日志
- 每次任务执行自动记录日志
- 日志包含：执行时间、执行结果、耗时、异常信息
- 可按任务名称、时间范围查询

### 相关接口
- 任务管理：`/job`（CRUD + 执行 + 暂停 + 恢复）
- 执行日志：`/jobLog`（分页查询）
- 任务订阅：`/jobSubscribe`（CRUD）
