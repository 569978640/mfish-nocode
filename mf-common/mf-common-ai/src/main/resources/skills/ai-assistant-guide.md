## AI 助手体系

平台内置 **7 大垂直领域 AI 助手**，每个助手绑定对应微服务的工具集，可通过自然语言直接操作系统。

### 助手分工

| 助手 | 路由路径 | 能力范围 |
|------|---------|---------|
| 通用助手 | `/assist/chat` | 平台介绍、通用问答、角色扮演 |
| 系统助手 | `/sys/assist` | 字典管理、日志查询、代码生成、数据库连接 |
| 认证助手 | `/oauth/assist` | 菜单管理、组织架构、角色权限、账号管理、租户管理 |
| 低代码助手 | `/nocode/assist` | 自助大屏、自助 API、组件管理 |
| 工作流助手 | `/workflow/assist` | 流程部署、流程实例、任务审批、待办查询 |
| 调度助手 | `/scheduler/assist` | 定时任务管理、执行日志查询 |
| 存储助手 | `/storage/assist` | 文件管理、文件资源查询 |

### 两种调用模式

1. **路由助手模式**（`/router`）：
   - 用户发送自然语言，LLM 自动判断应路由到哪个助手
   - 助手内部进行单次工具调用回答问题
   - 适合简单查询和单一操作

2. **智能体模式**（`/agent/chat`）：
   - Plan → Execute → Emit 自主规划执行
   - LLM 先规划任务步骤，再串行执行每步（可跨服务调用多个工具）
   - 适合复杂多步操作，如"创建一个请假流程并提交审批"

### 工具来源
助手可调用的工具来自三层能力引擎：
- **ToolCapabilityEngine**：Feign/OpenAPI 工具（自动扫描所有微服务接口）
- **McpCapabilityEngine**：MCP 协议外部工具（如智谱搜索、本地 MCP 服务）
- **SkillCapabilityEngine**：提示词级 Skill（如翻译、摘要等）

### OpenAI 兼容接口
平台提供 `/v1/chat/completions` 接口，兼容 OpenAI API 格式，支持流式和非流式响应，可接入任何支持 OpenAI 协议的客户端。

请针对用户的具体问题，说明应使用哪个助手或哪种调用模式。
