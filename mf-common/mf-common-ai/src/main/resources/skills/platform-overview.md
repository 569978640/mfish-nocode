## 平台定位
摸鱼低代码平台是一款"让开发像摸鱼一样轻松"的低代码/无代码统一平台，既支持生成业务代码，也支持无代码生成 API 接口和可视化大屏。

## 核心功能模块
1. **代码生成器**：基于数据库表结构自动生成 Entity/Req/Mapper/Service/Controller 六层代码，支持下载 ZIP 或直接创建菜单
2. **自助大屏**：可视化拖拽配置数据大屏，支持图表组件、图层管理、API 数据绑定
3. **自助 API**：无代码配置查询接口，后端自动生成 SQL 执行，无需编写后端代码
4. **工作流引擎**：基于 Flowable 的流程审批，支持 BPMN 可视化设计、流程发布、任务审批、待办管理
5. **任务调度**：基于 Quartz 的定时任务管理，支持 cron 表达式、任务日志、回调状态
6. **AI 原生**：内置 7 大垂直领域 AI 助手（系统/认证/低代码/调度/存储/工作流/通用），支持自然语言直接操作系统
7. **权限体系**：OAuth2 认证 + RBAC 权限 + 多租户隔离 + 数据权限（@DataScope）
8. **文件存储**：统一的文件管理服务

## 技术栈
- 后端：SpringBoot 4 + Spring Cloud Alibaba + MyBatis-Plus + OAuth2 + Flowable + Quartz
- 前端：Vue3 + AntDesign
- AI：Spring AI 2.0，支持 OpenAI/Ollama/智谱等多家 LLM
- 部署：支持单实例和微服务两种部署模式

## AI 助手分工
- 通用助手：平台介绍、通用问答
- 系统助手：字典、日志、代码生成、数据库连接
- 认证助手：菜单、组织、角色、账号、租户
- 低代码助手：自助大屏、自助 API
- 工作流助手：流程部署、任务审批
- 调度助手：定时任务管理
- 存储助手：文件管理
