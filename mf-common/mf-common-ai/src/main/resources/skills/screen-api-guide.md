## 自助 API（无代码接口开发）

平台支持通过可视化配置创建查询 API 接口，无需编写后端代码。

### 配置流程
1. 进入「低代码 → 自助 API」
2. 创建 API 文件夹（用于分类管理）
3. 新增 API 配置：
   - 填写 API 名称、请求路径、请求方式
   - 选择数据源（数据库连接）
   - 编写 SQL 语句（支持参数化查询）
   - 配置入参（名称、类型、是否必填）
4. 保存后即可通过配置的路径直接调用

### 数据表结构
- `mf_api`：API 配置主表（名称、路径、SQL、数据源）
- `mf_api_folder`：API 文件夹（树形分类）
- `mf_api_params`：API 参数配置（名称、类型、必填）

## 自助大屏（数据可视化）

平台支持可视化拖拽配置数据大屏，适用于数据展示和监控场景。

### 大屏组成结构
- `mf_screen`：大屏主配置（标题、宽高、背景）
- `mf_screen_charts`：图表组件配置（类型、数据、样式）
- `mf_screen_layers`：图层管理（位置、大小、层级）
- `mf_screen_layers_apis`：图层绑定的 API 数据源
- `mf_screen_folder`：大屏文件夹（树形分类）
- `mf_screen_relation`：组件联动关系
- `mf_screen_resource`：大屏资源管理
- `mf_screen_resource_api`：资源绑定的 API

### 配置流程
1. 进入「低代码 → 自助大屏」
2. 创建大屏，配置基础属性（标题、分辨率、背景）
3. 添加图层/图表组件，配置样式和数据源
4. 绑定自助 API 作为数据源
5. 配置组件联动（可选）
6. 预览并发布

### 与自助 API 的配合
大屏组件的数据来源主要依赖自助 API：
1. 先在自助 API 中创建数据查询接口
2. 在大屏图层中绑定该 API
3. 配置数据映射（API 返回字段 → 图表维度/度量）

### 工作流审批集成
大屏发布可接入工作流审批：
- 提交发布 → 触发审批流程 → 审批通过后正式发布
- 详见 workflow-audit 开发规范
