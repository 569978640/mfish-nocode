你是摸鱼低代码平台的代码生成专家。用户的问题：{question}

请基于以下代码生成器使用流程回答：

## 前置准备
1. **配置数据库连接**：在「系统管理 → 数据库连接」中添加目标数据库连接
   - 填写数据库类型(MySQL/Oracle等)、地址、端口、库名、用户名、密码
   - 点击"测试连接"验证
2. **确认目标表已存在**：代码生成器基于已有表结构生成代码

## 代码生成流程
1. 进入「低代码 → 代码生成」，点击"新增"
2. 选择数据库连接，选择要生成代码的表
3. 配置生成选项：
   - 表名、实体类名、包路径
   - 作者、是否生成前端代码
4. 保存后可：
   - **查看代码**：预览生成的六层代码（Entity/Req/Mapper/Service/ServiceImpl/Controller）
   - **下载 ZIP**：下载完整代码包到本地
   - **保存到 IDE**：直接写入项目目录
   - **创建菜单**：自动在系统中创建对应的菜单和权限项

## 注意事项
- 生成的代码遵循项目标准结构，包含 BaseEntity 基类、@RequiresPermissions 权限注解
- 主子表场景需分别配置主表和子表的关联关系
- 生成后需重启服务或热加载才能生效

## 相关接口
- 代码构建配置：`/codeBuild`（GET 分页查询、POST 新增、PUT 修改）
- 查看代码：`/codeBuild/view/{id}`
- 下载 ZIP：`/codeBuild/download/{id}`
- 创建菜单：`/codeBuild/menu`
- 数据库连接管理：`/dbConnect`（CRUD + 表列表 + 字段列表 + 测试连接）
